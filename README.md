# STEPZONE — інтернет-магазин кросівок

Багатосторінковий сайт магазину оригінальних кросівок. Чистий HTML + CSS + JavaScript, без фреймворків і без збірки.

---

## Як запустити

**Важливо:** товари підтягуються через `fetch()` з файлу `data/products.json`. Браузери блокують `fetch` до локальних файлів, тому сайт треба відкривати через локальний сервер:

```bash
# Варіант 1 — Python (є майже всюди)
python3 -m http.server 8000
# відкрити http://localhost:8000

# Варіант 2 — Node.js
npx serve .

# Варіант 3 — VS Code
# розширення "Live Server" → правою кнопкою по index.html → Open with Live Server
```

Якщо відкрити `index.html` просто подвійним кліком (протокол `file://`), сайт **все одно працюватиме**: у `assets/js/data.js` лежить резервна копія бази товарів, і скрипт автоматично перемикається на неї, коли `fetch` не спрацював.

## Що реалізовано (за вимогами завдання)

| Вимога | Де саме |
|---|---|
| Картки товарів генеруються через JS, а не вшиті в HTML | `app.js` → `SZ.productCard()` / `SZ.renderProducts()` |
| Отримання даних через `fetch` з JSON-файлу | `app.js` → `SZ.getData()` читає `data/products.json` |
| Додавання в кошик без перезавантаження сторінки | `SZ.Cart.add()` + подія `cart:change`, бічна панель кошика |
| Збереження кошика (LocalStorage + Cookies) | `app.js` → `Store` (LocalStorage, дубль у кукі на 30 днів) |
| Форма оформлення замовлення з очищенням кошика | `checkout.js` → валідація → `SZ.Cart.clear()` → екран успіху |
| **Просунуто:** зміна кількості кнопками +/− | `cart.js`, бічна панель, сторінка товару |
| **Просунуто:** підрахунок загальної вартості | `SZ.Cart.totals()` — сума, знижка, доставка, разом |
| **Просунуто:** пошук і фільтрація за категоріями | `catalog.js` + пошук з підказками в шапці |

### Додатково понад завдання

- Фільтри: бренд, категорія, розмір, ціна (від/до), стать, позначки (новинки / хіти / знижки)
- Сортування: популярні, новинки, ціна ↑↓, рейтинг, назва
- Активні фільтри показані «чипсами», кожен знімається окремо
- Синхронізація фільтрів з URL (`catalog.html?brand=Nike&cat=running`) — посиланням можна поділитись
- Пагінація «Показати ще»
- Пошук з живими підказками в шапці (з фото і ціною)
- Обране (сердечко) зі своєю сторінкою
- Промокоди: `STEP10` (−10%), `ZONE15` (−15%), `FIRST300` (−300 ₴)
- Безкоштовна доставка від 5 000 ₴ + прогрес-бар «додайте ще N ₴»
- Бічна панель кошика (drawer), що відкривається без переходу на іншу сторінку
- Блок «Ви нещодавно дивились» (історія в LocalStorage)
- Історія замовлень і збереження даних покупця (наступного разу форма вже заповнена)
- Валідація форм: ім'я, прізвище, український телефон, email, місто, відділення
- Синхронізація кошика між вкладками браузера
- Адаптив: 4 → 3 → 2 колонки, мобільне меню, повноекранна панель фільтрів
- Скелетони під час завантаження, тости-сповіщення, анімація появи блоків

## Про зображення

У кожного товару масив `images` із трьох елементів:

```json
"images": [
  "https://assets.vans.com/.../Old-Skool-Shoe-VANS-Black-White-HERO.png",
  "assets/img/vans-old-skool-1.svg",
  "assets/img/vans-old-skool-2.svg"
]
```

1. **Перше** — справжнє фото моделі з сайту бренду або великого ритейлера. Кожне посилання взяте зі сторінки, присвяченої саме цій моделі та розцвітці (артикул є в назві файлу або в шляху — наприклад `VN000D3HY28` для Old Skool).
2. **Друге і третє** — власні векторні ілюстрації цієї ж моделі в `assets/img/`.

### Як працює підміна

Якщо фото не завантажилось — посилання застаріло, немає інтернету, ритейлер прибрав товар — спрацьовує ланцюжок:

**фото → ілюстрація моделі → друга ілюстрація → намальована заглушка з назвою**

Підміняється завжди картинка **тієї самої моделі**, а не загальна «немає фото». Працює скрізь: у каталозі, на сторінці товару, у підказках пошуку, в кошику, у бічній панелі та при оформленні замовлення.

Реалізовано двома способами:
- `SZ.imgFallback(img, назва, масивImages)` — для елементів, створених у JS
- атрибут `data-fallback="файл1|файл2"` — для картинок, зібраних рядком HTML (обробник у `app.js`)

### Ілюстрації

96 файлів у `assets/img/`, по 3 на товар. Кожна намальована під конкретну модель: свій силует (`low`, `high`, `chunky`, `runner`, `trail`, `skate`, платформа) і своя розцвітка.

**Щоб замінити фото на свої:** покладіть файли в `assets/img/` і замініть перший елемент `images` у `data/products.json` (а також у `assets/js/data.js` — це резервна база).

## Як додати товар

Додайте об'єкт у масив `products` файлу `data/products.json`:

```json
{
  "id": "nike-air-max-90",
  "name": "Nike Air Max 90",
  "brand": "Nike",
  "category": "lifestyle",
  "gender": "unisex",
  "price": 6490,
  "oldPrice": null,
  "rating": 4.7,
  "reviews": 120,
  "badge": "new",
  "colors": ["Білий", "Сірий"],
  "sizes": [40, 41, 42, 43, 44],
  "images": ["url1", "url2", "url3"],
  "description": "Опис моделі.",
  "specs": { "Верх": "Шкіра", "Підошва": "Гума" },
  "stock": 10,
  "createdAt": "2026-08-22",
  "popular": false
}
```

Доступні `category`: `lifestyle`, `running`, `retro`, `basketball`, `training`, `trail`.
Доступні `badge`: `new`, `hit`, `null` (знижка визначається автоматично наявністю `oldPrice`).

## Дані, що зберігаються в браузері

| Ключ | Що зберігає |
|---|---|
| `sz_cart_v1` | вміст кошика |
| `sz_fav_v1` | обране |
| `sz_promo_v1` | застосований промокод |
| `sz_recent_v1` | нещодавно переглянуті товари |
| `sz_customer_v1` | дані покупця для автозаповнення форми |
| `sz_orders_v1` | історія останніх 10 замовлень |

Кожен ключ дублюється в cookie на 30 днів — якщо LocalStorage недоступний (приватний режим), кошик усе одно не втрачається.
